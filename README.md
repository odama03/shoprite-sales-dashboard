# Shoprite Nigeria — Sales Dashboard

## Overview
This project analyzes sales transaction data from Shoprite Nigeria 
across 4 store locations using Python.

## Tools Used
- Python
- Pandas
- Plotly
- Dash

## Dataset
300 rows of sales transactions including products, store locations, 
sales reps and monthly customer data.

## Dashboard Features
- KPI cards showing Revenue, COGS, Profit and Customers
- Product by Profit bar chart
- Store Location donut chart
- Sales Rep bar chart
- Monthly Customers line chart
